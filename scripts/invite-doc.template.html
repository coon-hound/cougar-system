Doing this yourself

Every command needs the database connection first. Run this once per terminal:

cd ~/dev/js/cougar-system
set -a; . ~/.cougar-migrate.env; set +a

Rebuild this page

Always current, because it reads the database. You never need to keep the file.

node scripts/invite-doc.mjs

See who has access, and who has not used their link

node scripts/issue-invites.mjs --list

Add one person

node scripts/issue-invites.mjs --person "JAMSON TAN" --d4 0028 --commit

Add everyone missing

Skips anyone already set up, so running it twice is safe.

node scripts/issue-invites.mjs --from-roster --role Commander --commit

Take access away

Someone posts out, or loses a phone. Two different things:

node scripts/issue-invites.mjs --revoke-invite <token> --commit   # link not yet used
node scripts/issue-invites.mjs --revoke-token  <token> --commit   # device already signed in

Revoking a link does not sign out a phone that already used it. If they were already in, you need --revoke-token as well. --list shows both.

Drop --commit to see what would happen

Every command that changes something is a preview without --commit. Nothing is written and you can run it as often as you like.

The “sent” ticks live in this browser only. They are a checklist for you, not a record of anything.
